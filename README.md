# 리드온 그림 놀이 — 화면

행사 부스용 그림 맞추기·따라 그리기의 **빌드된 화면 파일**만 있는 저장소입니다. 깃허브 페이지로 냅니다.

- 사이트: https://read-on-airlab.github.io/tf-event-site/
- 코드와 API 는 비공개 저장소에 있고, API 는 `https://readon.kr/event-api` 에서 돕니다.
- 이 저장소의 파일을 손으로 고치지 않습니다. 코드 저장소에서 `VITE_BASE=/tf-event-site/ VITE_API_BASE=https://readon.kr/event-api npm run build` 로 다시 만들어 통째로 바꿉니다.
